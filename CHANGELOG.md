# Changelog

## 0.9.0 beta (pre-release)

- Record default system audio sink monitor to WAV, MP3 or FLAC
- Live waveform visualization
- Optional post-record peak normalization with original preserved
- Handle default sink changes during recording
- gettext translations: Spanish, Portuguese (Portugal/Brazil), French, German and Italian
- Debian package with application icon

The public beta installer has not yet been released.
